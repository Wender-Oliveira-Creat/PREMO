# PREMO — Monitoramento de Pressão Arterial

Sistema web desenvolvido para auxiliar no acompanhamento da pressão arterial, permitindo consultar o histórico de medições e visualizar dados por meio de gráficos.

## Sobre o projeto

O PREMO é um projeto acadêmico desenvolvido durante a graduação em Sistemas de Informação. A proposta é oferecer uma interface simples e organizada para facilitar o acompanhamento das medições de pressão arterial.

## Funcionalidades

- Registro e consulta de medições
- Histórico de pressão arterial
- Visualização gráfica dos dados
- Armazenamento local de informações

## Tecnologias utilizadas

- HTML
- CSS
- JavaScript

## Objetivo acadêmico

Aplicar conhecimentos de desenvolvimento web na construção de uma solução digital, trabalhando conceitos de interface, organização de dados e desenvolvimento de software.
